01  /  What an app is

A folder. Nothing to
provision.

No Dockerfile, no database to spin up, no auth library, no environment to wire. Three things, and the platform supplies the rest through one ctx object.

standup/
  app.json            {"name": "Standup Notes"}
  public/index.html   the frontend
  api/notes.js        one file per route
// api/notes.js
export default (req, ctx) => ({
  json: ctx.db.all(
    'select * from notes order by id desc'
  )
})
02  /  Sharing

Send a link. They
sign in with email.

Your app sees whoever opened it as ctx.user.email. Roles are user and editor.

bob@example.comjust Bob, after he signs in
domain:acme.comanyone with an email at that domain
publicanyone with the link, no sign‑in
03  /  What it deliberately is not

Honest about its edges.

  • noNot a scale‑out cloud. It is for software that will only ever have a few users.
  • noNot a place to let strangers deploy code. Open it only to people you would hand a shell.
  • noNot a code generator, and not a no‑code builder. It is the deploy‑and‑share layer.
  • noNo lock‑in. smallcloud export hands back your source, database and files.
